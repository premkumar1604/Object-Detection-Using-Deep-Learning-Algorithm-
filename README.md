# Object Detection Using Deep Learning Algorithm

## 📌 Project Overview

This project implements a **real-time object detection system using the YOLOv8 deep learning algorithm**. The system detects and classifies objects from images and video streams using a custom dataset.

## 🚀 Features

- Real-time object detection
- Custom dataset creation and annotation
- Bounding-box labeling
- Data augmentation for improved model performance
- YOLOv8-based object detection
- Transfer learning
- Image and video stream detection
- Confidence threshold optimization

## 🧠 Model

The project uses **YOLOv8 (You Only Look Once)** for fast and efficient object detection.

### Dataset

A custom dataset was created containing objects such as:

- Helmet
- Tray
- Bucket
- Box
- Other project-specific objects

The dataset was prepared using annotation and data augmentation techniques.

### Training

- Dataset split: **80% Training / 20% Validation**
- Transfer learning used for efficient training
- Parameters such as epochs, batch size, and confidence threshold were tuned.
